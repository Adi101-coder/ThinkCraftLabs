\section{Introduction}

\subsection{Purpose}
ThinkCraft Lab is a full-stack web application combining e-commerce for 3D printing products with an events management system for students and makers. It provides a marketplace for browsing and purchasing 3D printed products, accessing design services, and engaging through workshops, competitions, and courses with efficient order management and real-time event registration.

\subsection{Intended Audience}
This document targets full-stack developers (React/Node.js), project managers, QA teams, stakeholders, and end users including customers, students, event creators, and administrators.

\subsection{Project Scope}
\textbf{E-commerce:} 50+ products across 3 categories with cart, wishlist, checkout with coupons (10-25\% off), and order tracking.

\textbf{Events:} Create/manage workshops, competitions, courses with registration tracking, live indicators, and attendance management.

\textbf{Users:} Four roles - Guests (browse), Customers (purchase/register), Event Creators (manage events), Admins (full access with analytics).

\section{Overall Description}

\subsection{Product Perspective}
ThinkCraft Lab uses modern client-server architecture with React 18 SPA (TypeScript, Vite, Tailwind CSS, Framer Motion/GSAP) for frontend, Node.js/Express.js REST API with session auth for backend, and MongoDB/Mongoose for data persistence. Deployed on Vercel (frontend CDN), Render (containerized backend), and MongoDB Atlas (managed database with replica sets).

\subsection{Product Functions}
\textbf{Authentication:} User registration/login with bcrypt hashing, 7-day sessions, role-based access, profile management.

\textbf{E-commerce:} 50+ products with images, descriptions, pricing across 3 categories. Pagination (9/page), filtering, size selection (S/M/L/XL), cart with localStorage persistence, wishlist, real-time totals.

\textbf{Checkout:} Shipping info collection, multiple payment methods (Credit Card, PayPal, COD), coupon validation (FIRST10/SAVE15/MEGA25/TEST10), unique order numbers, status tracking (pending/processing/shipped/delivered).

\textbf{Events:} Create with title, description, category, images, date, location, live status. Browse chronologically, filter by category, one-click registration, prevent duplicates, view registrations.

\textbf{Admin:} Dashboard with statistics (users, events, registrations, live events), manage all events, view registrations, delete content.

\subsection{User Classes}
\textbf{Guests:} Browse products/events, view public pages. Must register for purchases/registrations.

\textbf{Customers:} All guest features plus cart/wishlist, purchases, order tracking, event registration, profile management.

\textbf{Event Creators:} All customer features plus create/edit/delete own events, view registrations.

\textbf{Admins:} Complete access including dashboard, statistics, manage all events/users.

\subsection{Operating Environment}
\textbf{Client:} Chrome 90+, Firefox 88+, Safari 14+, Edge 90+ on Windows 10+, macOS 10.15+, Linux. Responsive 320px-2560px.

\textbf{Server:} Node.js 18+, MongoDB 5.0+, 512MB RAM, 1GB storage.

\textbf{Production:} Vercel (CDN, HTTPS), Render (containerized, auto-scaling), MongoDB Atlas (replica sets, backups).

\subsection{Constraints}
\textbf{Technology:} React 18+, Node.js, Express, MongoDB, TypeScript required.

\textbf{Security:} Bcrypt (10 rounds), session auth, HTTPS, CORS configuration.

\textbf{Performance:} Page load <3s, API <500ms, 100+ concurrent users, optimized queries.

\section{System Features}

\subsection{Authentication \& Authorization (Priority: High)}
User registration with username, email, password (min 6 chars). Email/username uniqueness validation. Bcrypt password hashing. Secure login with 7-day sessions. Admin redirect to dashboard. Logout destroys session. Profile updates with validation. Password changes require current password.

\subsection{Product Catalog \& Shopping (Priority: High)}
Display 50+ products with images, names, prices, descriptions. Three categories with filtering. Pagination (9/page). Product details show sizes, quantity selector, related products, specifications. Cart allows add/remove, quantity updates, size selection, localStorage persistence, real-time totals. Wishlist prevents duplicates, allows move to cart.

\subsection{Checkout \& Orders (Priority: High)}
Requires authentication. Collects shipping info (address, city, state, zip, country). Payment methods: Credit Card, PayPal, COD. Coupon validation (FIRST10 10\%, SAVE15 15\%, MEGA25 25\%, TEST10 10\%). Generates unique order numbers (ORD-timestamp-random). Stores complete order details. Clears cart post-order. Order history with status tracking. Detailed order view with items, prices, shipping.

\subsection{Events Management (Priority: High)}
Create events with title, description, category (Workshop/Competition/Course/Other), images, date, location, live status. Display chronologically with category filtering. Live events in separate section. One-click registration, prevent duplicates. Unregister option. Track registrations with usernames/timestamps. Creators edit/delete own events, view registrations. Admins manage all events.

\subsection{User Profile \& Settings (Priority: Medium)}
Profile displays username, email, creation date, admin status, order history, event registrations. Settings allow username/email updates with uniqueness validation. Password changes require current password, min 6 chars. Notification preferences. Integrated FAQ section.

\section{Database Design}

\subsection{Collections}
\textbf{Users:} \_id, username* (unique), email* (unique), password (hashed), isAdmin (default false), createdAt. Indexes: username, email.

\textbf{Orders:} \_id, userId, orderNumber* (unique), status (default 'pending'), subtotal, discount, couponCode, totalAmount, shipping (address, city, state, zip, country), paymentMethod, items[productId, productName, productPrice, productImage, size, quantity], createdAt. Indexes: userId, orderNumber, createdAt.

\textbf{Events:} \_id, title, description, category (enum), images[], date, location, isLive, createdBy, createdByUsername, registrations[userId, username, registeredAt], timestamps. Indexes: category, isLive, date, createdBy.

\subsection{Relationships}
Users (1)(Many) Orders | Users (1)(Many) Events (creator) | Users (Many)(Many) Events (registrations embedded)

\subsection{Integrity}
Mongoose schema validation, unique indexes, required fields, enum validation, ObjectId references, atomic transactions.

\section{System Architecture}

\subsection{Three-Tier Design}
\textbf{Presentation:} React 18 SPA with TypeScript, Vite build tool, Tailwind CSS, Wouter routing, TanStack Query (caching), Framer Motion/GSAP animations. Responsive 320px-2560px.

\textbf{Application:} Node.js/Express.js REST API, express-session auth, route handlers, storage layer, middleware (auth, CORS, error handling), input validation.

\textbf{Data:} MongoDB document storage, Mongoose ODM, indexed collections, connection pooling, replica sets.

\subsection{Components}
\textbf{Frontend:} Pages (Home, Shop, Work, About, Students, Profile, Admin, Cart, Wishlist, Checkout, Order Confirmation), Layouts (Navigation, Footer), Contexts (Auth, Shop).

\textbf{Backend:} Routes (Auth, Orders, Events, Users, Admin), Models (User, Order, Event), Storage layer, Middleware.

\subsection{Deployment}
\textbf{Vercel:} Auto-build from GitHub, CDN, HTTPS, env: VITE\_API\_URL.

\textbf{Render:} Containerized, auto-scaling, env: MONGODB\_URI, SESSION\_SECRET, NODE\_ENV, FRONTEND\_URL.

\textbf{MongoDB Atlas:} M0 free tier (512MB), replica sets, backups, network access configured.

\section{API Endpoints}

\textbf{Auth:} POST /api/auth/signup (register), POST /api/auth/login (authenticate), POST /api/auth/logout (end session), GET /api/auth/me (current user).

\textbf{Orders:} POST /api/orders (create), GET /api/orders (list user orders), GET /api/orders/:orderId (details).

\textbf{Events:} GET /api/events (list, query: category/live), POST /api/events (create), GET /api/events/:eventId (details), PUT /api/events/:eventId (update), DELETE /api/events/:eventId (delete), POST /api/events/:eventId/register (register), DELETE /api/events/:eventId/register (unregister).

\textbf{User:} PUT /api/user/profile (update), PUT /api/user/password (change).

\textbf{Admin:} GET /api/admin/stats (statistics).
