\section{DFD Level 1 - Process Decomposition}
The Level 1 DFD breaks down the system into six major processes: Authentication \& User Management (1.0), Product \& Shopping Management (2.0), Order Processing (3.0), Event Management (4.0), Event Registration (5.0), and Admin Operations (6.0). These processes interact with four data stores: Users Database (D1), Orders Database (D2), Events Database (D3), and Session Store (D4).

\section{DFD Level 2 - Authentication \& User Management}
The Level 2 DFD provides detailed decomposition of Process 1.0 (Authentication \& User Management), showing the internal sub-processes: User Signup (1.1), User Login (1.2), Session Management (1.3), Profile Update (1.4), and Password Management (1.5). This diagram illustrates how user authentication and account management operations interact with the Users Database and Session Store.
